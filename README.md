# IWS-W2026

Website for the Internal Waves Service Workshop 2026, hosted by AIR Centre.

**Live site:** https://aircentre.github.io/IWS-W2026/

## Event Details

- **Date:** 14–16 April 2026
- **Location:** Lisbon region, Portugal
- **Format:** In-person, invitation only

## About

The workshop brings together international experts in ocean internal waves, remote sensing, and physical oceanography to advance the Internal Waves Service (IWS)—a near-real-time global detection system using Sentinel-1 SAR imagery.
